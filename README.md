MHD — Mazen Khaled Development (Agency Website)

> الموقع الرسمي لبراند MHD — خدماتنا، أحدث مشاريعنا، المجتمع التعليمي، وابدأ مشروعك معنا.

The official landing site for the MHD brand (Mazen Khaled Development): services, latest projects, the MHD educational community and a "start your project with us" section.

## Features

- Arabic RTL single-page agency site
- Sections: hero, services, projects, community, contact/CTA
- Custom CSS (`style.css`) and JS (`script.js`), no framework

## Tech Stack

- Vanilla HTML/CSS/JS, fully static

## Running

Open `index.html`, or deploy to any static host.
